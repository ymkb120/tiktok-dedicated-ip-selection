## 机房 IP、原生 IP、住宅 IP，三个概念别混着用

TikTok 判断一个账号是不是真人，看设备、行为、网络环境三层，IP 是最先被判断的那一层。

**机房 IP** 的 ASN 归属是机房或云服务商，平台一扫就知道是商用出口。几十块一年的廉价 VPS 基本都是这一类。

**原生 IP** 指 IP 的注册归属地和服务器实际所在国一致。做 TikTok 这是及格线，不是加分项。

**住宅 IP** 更进一步，IP 段是从当地 ISP 的家庭宽带里出来的，在风控眼里更接近一个在家刷手机的本地用户。**双 ISP** 指这个 IP 同时在两个 ISP 名下注册，线路稳定性和信任度比单 ISP 高一档。

这里有个很实际的坑：原生 IP 不等于家宽 IP。WePC 官网把这两类标得很清楚，德国款 AUD$10.90 写的是“非家宽 IP”，新加坡两款写的是“原生 IDC IPv4”。网上流传的一些 WePC 套餐整理表把新加坡写成“原生家宽”，跟官网标注对不上。冲着“家宽”两个字去买新加坡款，买回来大概率不是你想要的东西。

看套餐名只看价格不够，要点进产品页看那行 IP 属性说明。IP 类型直接决定它在风控眼里是什么身份，配置差一核 512MB 内存反而不重要。
